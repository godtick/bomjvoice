# bomjvoice

Развлекательное TTS-приложение для Windows: печатаешь текст — он звучит из твоего микрофона (как Soundpad).
Работает локально и офлайн: синтез — через голоса SAPI5, установленные в системе (RHVoice, IVONA и любые другие).

## Что умеет

- **Главный**: ввод текста, Enter — и текст озвучивается в микрофон.
- **История**: всё, что вы вводили, с кнопкой «Повторить».
- **Голос**: выбор голоса из установленных в системе SAPI5-голосов. Если голосов нет — появляется кнопка
  «Установить голоса (русские / английские)»: русский пакет ставит голоса RHVoice (Aleksandr, Elena)
  и IVONA 2 Maxim, английский — RHVoice Alan и Clb.
- **Бинды**: свои горячие клавиши на заранее заданные фразы.
- **Настройки**: 8 тем оформления, громкость, скорость речи, русский/английский интерфейс.
- **Оверлей (Alt+V)**: табличка «Сказать…» по центру экрана поверх игры. Enter — озвучить, Esc — скрыть.
- **Автопроверка зависимостей**: при запуске приложение само проверяет и устанавливает драйвер
  виртуального микрофона VB-CABLE (как Discord проверяет обновления).

## Как это работает

```
текст -> SAPI5 (голоса RHVoice / IVONA, локально) -> wav -> виртуальный микрофон (VB-CABLE) -> Discord/игры/Zoom
```

- **VB-CABLE** — бесплатный драйвер виртуального аудиоустройства. Windows *физически не позволяет*
  подменить сигнал микрофона без такого драйвера (это ограничение ОС, а не приложения), поэтому он ставится
  один раз, автоматически. В Discord/игре просто выбираете микрофон «CABLE Output».
- **RHVoice** — свободные голоса с поддержкой SAPI5.

## Запуск из исходников

Нужен Windows 10/11 (64 бита) и Python 3.11:

```powershell
python -m venv .venv
.\.venv\Scripts\pip install -r requirements.txt
.\.venv\Scripts\python main.py
```

## Сборка

```powershell
# 1. (опционально) положите рядом с проектом папку ivona_setup с голосом IVONA 2 Maxim —
#    она будет вшита в exe и голос Maxim установится автоматически
# 2.
.\build.ps1
```

Понадобятся: Python 3.11 (с python.org, при установке отметьте «Add to PATH»).
На выходе: `dist\bomjvoice.exe` — единый самодостаточный файл, это и есть готовая программа.
Если дополнительно установлен Inno Setup (jrsoftware.org, бесплатный) и рядом лежит
`installer\VBCABLE_Setup_x64.exe` (см. installer/README-DRIVER.txt), соберётся
и установщик `dist_installer\bomjvoice-Setup.exe`.

## Установка конечному пользователю

Приложение — один файл `bomjvoice.exe`, ничего устанавливать не нужно.
Программа запускается **только от имени администратора** (Windows сама спросит
права при запуске) — они нужны для установки драйвера и голосов:

1. Скачать `bomjvoice.exe` из раздела Releases.
2. Запустить. При первом запуске программа сама проверит зависимости и установит
   драйвер виртуального микрофона VB-CABLE (после установки драйвера может
   понадобиться перезагрузка).
3. Если голосов нет — на вкладке «Голос» появится кнопка «Установить голоса»
   (русские или английские, нужен интернет один раз).
4. В Discord/игре выбрать микрофон **«CABLE Output (VB-Audio Virtual Cable)»**. Готово.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| **Alt+V** | оверлей «Сказать…» |
| Enter / Esc | озвучить / скрыть оверлей |

## Структура

```
bomjvoice/
  main.py               # точка входа (и для PyInstaller)
  app/
    core/               # tts_engine, audio_out, driver, voices_setup, ivona_setup,
                        # hotkeys, history, settings, i18n
    ui/                 # main_window (4 вкладки), overlay
  bomjvoice.spec        # PyInstaller
  build.ps1             # сборка exe + установщика одной командой
  installer/install.iss # Inno Setup
```
