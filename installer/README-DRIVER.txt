В эту папку положите файл VBCABLE_Setup_x64.exe
==============================================

1. Откройте в браузере:  https://vb-audio.com/Cable/
2. Нажмите оранжевую кнопку DOWNLOAD (бесплатно, без регистрации).
3. Распакуйте скачанный ZIP — внутри файл VBCABLE_Setup_x64.exe.
4. Скопируйте его в эту папку (рядом с install.iss).
5. Запустите build.ps1 — готовый Setup.exe сам установит драйвер
   пользователю в тихом режиме (ни о чём спрашивать не будет).

Это нужно сделать ОДИН РАЗ на вашей машине, чтобы собрать установщик.
Конечным пользователям ничего скачивать не нужно.
